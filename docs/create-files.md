# Create a file

At the end of this page you have a Word, Excel or PDF file written by jade.

Pick the "Créer un fichier" mode, or ask for a file in automatic mode, and say what you want. jade supports Word, Excel, PDF, PowerPoint, CSV, text, Markdown and HTML.

Files are always written to `Documents\Jade` in your profile, never next to your source documents, which jade only reads. A file card appears in the conversation and opens the file.

Simple Markdown in the answer becomes headings, lists, tables and bold text. In Excel and CSV files, a cell that starts with `=`, `+`, `-` or `@` gets an apostrophe in front, so it cannot run as a formula.
