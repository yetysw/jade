# jade

jade is a document assistant for Windows. It indexes the folders you choose on your own PC or server, answers questions in French, and shows which passages it used. The documents stay on the machine; only the question and a few short excerpts go to the inference server you configure.

Start here:

- [Install jade](install.md): the installer, what it asks, where files go.
- [First run](first-run.md): add your folders and ask a first question.
- [How jade protects your data](security.md): what leaves the PC, and what does not.
